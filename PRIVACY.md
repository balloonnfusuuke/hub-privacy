# Privacy Policy - hub

hub is a personal tool built and used only by its owner (Fusuke Yasuda) to organize his own Gmail inboxes.

- Data accessed: Gmail messages and labels of the owner's own Google accounts, via the Gmail API (gmail.modify scope).
- Use: Only to read, label, and archive the owner's own email on his own computer.
- Storage: OAuth tokens and any processed data stay on the owner's local machine. Nothing is sold, shared, or sent to third parties.
- Users: The app is not offered to the public. No other users' data is collected.
- Deletion: Access can be revoked at any time from Google Account > Security > Third-party connections.

Google API usage complies with the Google API Services User Data Policy, including the Limited Use requirements.
